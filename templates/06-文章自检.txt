# 公众号文章自检规则（L1–L4）

对附件公众号文章按照以下 L1 至 L4 规则进行自检并修改。

---

## 自检的最高准则

在开始逐项扫描之前，先记住一件事：**这四层检查不是四张分开的清单，而是一根从"规范"走向"活人感"的坡道。**

L1 保证不出错，L2 保证像老欧，L3 保证有深度，L4 保证有粘性。前三层是必要条件，L4 才是充分条件。一篇通过了 L1–L3 但在 L4 失手的文章，只是一篇"没毛病"的文章，不是一篇"值得转发"的文章。

自检的目的不是让文章"合格"，是让文章"有人愿意读完并转发给朋友"。

---

## L1 硬性规则检查（自动扫描层）

这一层检查的是绝对不能违反的规则，类似代码的语法检查。任何一项不通过就必须修复，没有例外。

### L1-1 禁用词扫描

全文搜索以下词汇，出现则必须替换：

- "说白了" → 换成"坦率的讲"、"其实就是"
- "意味着什么" / "这意味着" → 换成"那结果会怎样呢"、"所以呢"
- "本质上" → 换成"说到底"、"其实"
- "换句话说" → 换成"你想想看"、"也就是说"
- "不可否认" → 直接删掉，换成正面陈述
- "综上所述" / "总的来说" → 换成具体的回扣句
- "首先...其次...最后" → 用自然的转场词替代
- "值得注意的是" / "不难发现" → 删掉，直接说

### L1-2 禁用标点扫描

全文搜索以下标点，出现则必须替换：

- 冒号"：" → 用逗号替代
- 破折号"——" → 用逗号或句号替代
- 双引号""或"" → 用「」替代，或直接不加引号

### L1-3 结构性套话扫描

检查是否出现以下模式：

- "让我们来看看..." / "接下来让我们..."
- "在当今...的时代" / "随着...的发展"
- 连续使用 bullet point 罗列观点（超过 3 个就需要改成散文叙述）
- 大段加粗（超过 2 行的加粗几乎肯定是过度结构化）

### L1-4 工具名检查

确认所有提到的 AI 工具 / 产品都使用了具体名称，没有出现"AI 工具""某个模型""相关技术"等空泛表述。

一个具体的产品名，比十句"某类工具"更有可信度。这不是文风问题，是"读者信不信你真的用过"的问题。

**通过标准**：以上四项扫描零命中。

**修复方式**：逐个替换，用推荐口语化词组中的表达替代。

---

## L2 风格一致性检查（模式匹配层）

这一层检查文章是否符合老欧的写作模式，类似代码的单元测试。每一项都给出"是 / 否"判断。

### L2-1 开头检查

- 是否从一个具体的、当下的事件 / 场景切入？（不是宏大叙事）
- 第一句话是否让读者产生"然后呢？"的冲动？
- 有没有使用任何教科书式开头？

好的开头做的其实是一件事，**制造一个知识缺口**。让读者意识到，有件他"以为自己知道，其实并不知道"的事情正在发生。这个缺口越具体、越贴身，读者越想读下去。

如果读完开头，读者心里没有"然后呢"这三个字，重写。

### L2-2 节奏与结构检查

- 是否有长短句交替？（连续 3 句以上句式长度相近 = 节奏呆板）
- 是否有一句话独立成段的"断裂"效果？（全文至少出现 3 次）
- 偏离主线的段落后面是否有"扣主线句"拉回来？
- 有没有用疑问句来制造节奏的刹车和转向？
- 是否避免了不必要的小标题？（除非是分条目的方法论文章，否则不应出现 markdown 标题或加粗小标题，靠口语化转场自然衔接）

### L2-3 口语化检查

- 是否使用了推荐口语化词组？（全文至少出现 8-10 个不同的口语化表达）
- 有没有论述中的故意打破？（重复强调、中途打断、省略主语等）
- 有没有至少一处自嘲或承认不足？
- 标点是否用来表达情绪？（"。。。""？？？""= ="至少出现其中一种）

自嘲和承认不足这一条要单独说一句。它看起来只是风格要求，实际是**可信度的支柱**。一篇全程"我很懂""我做对了"的文章，读者会自动打折；一篇里出现一句"我当时也没想明白，绕了一大圈才发现自己错了"，反而会让读者更愿意相信你后面说的所有话。

### L2-4 标点禁令二次确认

- 全文是否完全没有冒号、破折号和双引号？（AI 容易在修改过程中重新引入这些标点，需要二次确认）

**通过标准**：L2-1 全部通过，L2-2 至少 3/4 通过，L2-3 至少 3/4 通过，L2-4 通过。

**修复方式**：逐段检查，对不符合的段落进行改写。重点关注那些"读起来像在写报告"的段落。

---

## L3 内容质量检查（深度审查层）

这一层检查内容本身的深度和说服力，类似代码的集成测试。

### L3-1 观点支撑检查

- 每个核心观点是否都有具体的人 / 场景 / 细节 / 数据支撑？
- 有没有空泛的观点只有论断没有例证？

抽象的观点在读者脑子里不会成像。同一句"这个工具很好用"，一百个读者会浮现一百种理解，甚至可能完全没有画面。而"我用它写了 5 篇文章，其中 3 篇的阅读量翻了倍"这种表达，所有读者脑子里想的都是同一件事。**具体，是让不同人的理解归拢到同一个点的唯一方式。**

审查时问一句：这段话如果换一个数字、换一个场景、换一个细节，会不会立刻更有说服力？

### L3-2 知识输出方式检查

- 知识点是否以"聊着聊着顺手掏出来"的方式呈现？
- 有没有出现"下面我来介绍""首先需要了解"这种教科书式科普？
- 引用（论文、书籍、历史）是否自然融入论述，像"聊着聊着想起来的"而不是"我特意去查的"？

### L3-3 文化升维检查

- 有没有至少一处从具体事件连接到更大的文化 / 哲学 / 历史参照物？
- 这个连接是否自然？

升维的克制原则是，**从具体出发，最后落在读者的身份认同上**，而不是落在宏大叙事上。"时代变了"是空话，"我们这些从纸质书时代过来的人，可能是最后一批还愿意慢慢读完一整本书的人"才是能打动人的话。前者在讲世界，后者在讲"我是谁"。

### L3-4 对立面与同理心检查

- 在讲核心观点时，是否有对对方立场的理解和承认？
- 有没有先站到读者的处境里，再给出自己的视角？

### L3-5 文章类型专项检查

根据文章原型做针对性检查：

- **调查实验型** → 有没有"亲自下场"的叙事感？过程是否有层层递进的发现？意外是分散在整个过程里，还是全憋到了结尾？
- **产品体验型** → 有没有真实的使用场景？有没有跟其他产品的自然对比？至少有没有一处让读者觉得"这人没在替它说好话"的具体槽点？
- **现象解读型** → 是否有"观察 → 好奇 → 研究 → 升维"的推进？核心判断是否有"反直觉"的锐度，还是所有人都会点头的平庸话？
- **工具分享型** → 有没有个人故事铺垫？效果展示是否让人"卧槽"？
- **方法论分享型** → 每节是否都落到了可执行行动？是否坦诚说明了学习成本和失败点？有没有谦逊铺垫？每条方法后面有没有一个可以让读者"在心里预演一遍"的场景？

### L3-6 逐一展示检查

- 如果涉及多个产品 / 案例的比较，是不是用了逐一展示（每个带吐槽点评）而不是一次性罗列？

**通过标准**：L3-1 和 L3-2 必须全部通过，L3-3 至 L3-6 中至少通过相关项（根据文章类型，有些项目可能不适用则跳过）。

**修复方式**：需要重新审视不通过的段落，补充案例、改写知识输出方式、或调整文化升维的自然度。

---

## L4 活人感终审（最终人格层）

这是最重要也是最主观的一层。这一层不是逐项检查，而是以读者的视角通读全文，回答一个核心问题：

**"读完这篇文章，我感觉是一个有见识的普通人在认真跟我聊一件打动他的事，还是一个 AI 在给我输出信息？"**

具体的感知维度：

### L4-1 温度感

- 文中的情绪表达是体感记忆（"我当时就愣住了""鼻子一酸"）还是知识性描述（"我感到非常震撼"）？
- 如果有人物描写，这个人物是否让你"能感觉到他的体温"？

情绪不是靠形容词堆出来的，是靠**具体的身体反应**传出来的。"后背发凉""手心出汗""看完那条消息我在厕所坐了十分钟"——这些句子之所以有力，不是因为它们文采好，是因为它们让读者的身体也跟着有了反应。

### L4-2 独特性

- 这篇文章是否有"只有老欧才会写出来的角度"？
- 还是换一个 AI 博主也能写出差不多的东西？

这一条其实是在问一个更硬核的问题，**这篇文章配不配被转发**。人们不会转发一篇"任何人都能写出来"的文章，他们只会转发那种"这个角度我怎么没想到"或者"这话说出了我一直想说但没说清楚的东西"的文章。如果一篇文章通篇都很正确、很流畅，但没有任何一句让读者产生"咦，这个说法有意思"的顿挫感，那它注定沉底。

### L4-3 姿态检查

- 文章的语气是不是"一个有见识的普通人在认真聊一件打动他的事"？
- 有没有不自觉地滑入了"导师在教学生"或"品牌在做营销"的姿态？

### L4-4 心流检查

- 从头到尾读，有没有哪个地方你的注意力断掉了？需要回头理解逻辑？
- 如果有，那个地方就是需要修复的节奏问题。

### L4-5 转发冲动检查

读完通篇之后，问自己最后一个问题，**你会不会把这篇文章转给一个具体的朋友？** 不是"这篇写得不错"，也不是"值得收藏"，而是脑子里能立刻浮现出一个具体的人——"这篇我要转给某某某看"。

如果答不上来是谁，说明文章还差最后一步。它可能已经不错了，但还没有产生那种"我必须让某个人也看到"的冲动。而所有真正广泛传播的文章，几乎都是靠这种"点对点"的转发扩散出去的，不是靠算法推。

**通过标准**：L4-1 到 L4-4 整体感觉"这像是真人写的"。L4-5 能想到至少一个具体的转发对象。如果任何一项让你觉得"这段 AI 味太重了"，就需要返工。

**修复方式**：这一层没有机械的修复方法。核心操作是，把"AI 味重"的段落找出来，想象老欧本人会怎么说这段话，然后用更口语、更私人、更不完美的方式重写。
