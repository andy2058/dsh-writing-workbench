# 老欧拾光记 · 封面生成

这个环节的提示词由工作台自动编译：你填的标题、摘要、画面隐喻 + 选定的视觉风格 + 画幅比例，会按 cover-master 的「封面提示词蓝图」拼成一条完整的图片生成提示词，直接交给火山方舟的豆包 seedream 出图。

此处的模板文本**不参与**图片提示词的拼装，它只在你把封面提示词发送到会话时，作为给模型的前置说明使用。

## 使用顺序

1. 先在「标题与封面摘要」环节拿到定稿标题；
2. 回到「封面生成」，把标题、主视觉标题、副标题、内容摘要填好；
3. 选一种视觉风格（17 选 1）和画幅比例（公众号 2.35:1 / 小红书 3:4 / 横版 5:2）；
4. 预览区就是最终提示词，可以手改；
5. 填火山方舟 API Key，点「生成封面」，图会直接存进本次的稿件目录。
