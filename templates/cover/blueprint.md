# Cover Master 提示词蓝图

本蓝图定义最终封面提示词的完整结构。`references/styles/{style-id}.md` 是可复用视觉风格原子，本蓝图是封面形态；最终提示词必须把选定风格原子编译进本蓝图，读起来像一条完整、独立的图片生成提示词。
不要带空占位符原样粘贴本蓝图；要用派生的文章字段与选定风格锚点填充。

## 最终提示词必需结构

```text
# {风格名} cover prompt
你是一位顶级封面艺术总监、编辑视觉设计师、字体设计师和图片生成提示词导演。
为 {平台} 生成一张封面图，画幅比例 {比例}。
必须使用选定视觉风格：{风格名} / {风格id}。
该风格不是装饰滤镜。封面的每个关键决策都必须通过该风格的视觉语言实现。

## 输入
- 标题 / 主题：{title_or_topic}
- 标题层级：
  - A 层 / 主视觉标题：{短而有冲击力的标题}
  - B 层 / 完整标题：{完整标题或完整含义}
  - C 层 / 副标题或小字：{subtitle}
- 平台：{platform}
- 画幅比例：{ratio}
- 输出尺寸：{输出尺寸或自动}
- 输出模式：{单张 / 多尺寸套图的其中一员}
- 语言：{语言}
- 用途：{use_case}
- 短语境摘要：{summary}
- 视觉主体：{visual_subject}
- 受众：{audience}
- 情绪：{mood}
- 视觉隐喻：{metaphor}
- 禁用元素：{banned_elements}

## 内容理解
先理解源材料再构图，但不要在画面里输出分析。
只用文章的派生字段，不要粘贴文章正文进画面、提示词、元数据或小字系统。
封面必须传达：
1. 第一眼看清主题是什么。
2. 第二眼看懂核心张力、洞见或隐喻。
3. 为什么这张封面属于所选风格，而不是通用封面模板。

## 封面目标
生成一张刻意设计的编辑封面，不是通用插画、PPT 封面、课程封面、广告或信息卡。
主标题必须完整、准确、清晰可读。源标题过长时使用上面的标题层级：
- A 层：短而有冲击力的视觉标题。
- B 层：完整标题或完整含义。
- C 层：副标题、语境行、标签或少量编辑小字。

## 风格落地
应用所选风格不可妥协的锚点：
- 风格锚点：{style_anchors}
- 封面形态适配：{cover_shape_adaptation}
- 必须保留：{must_preserve}
- 风格特有禁用：{avoid_when_applying_to_cover}
这些锚点必须可见地影响：
1. 主标题处理。
2. 视觉主体构建。
3. 背景或空间系统。
4. 辅助文字与标签系统。
5. 纹理、材质、色彩或渲染方式。
6. 视觉隐喻。
不要声称存在画面里实际看不到的风格特征。

## 构图
按所选风格设计封面专属构图，定义：
- 主视觉中心：{primary_visual_center}
- 次级视觉元素：{secondary_visual_elements}
- 背景或空间系统：{background_space_system}
- 前后景层次：{layering_strategy}
- 阅读路径：{reading_path}
- 传播约束：主题必须在快速滚动的社媒信息流中一眼可读。

## 图文关系
标题、主体和风格必须融合。
标题不能是贴在无关图片上的说明文字。所选风格必须决定文字如何在画面中存在：
- 主标题在哪里。
- 副标题如何承载。
- 标签、日期、标记或小字如何表现。
- 图像、物体、纹理或几何如何与字形互动。

## 字体
使用适合 {风格名} 的字体。
规则：
- 保证中文汉字正确。
- 主标题保持可读。
- 不裁切、不错拼、不过度扭曲关键文字。
- 辅助文字只少量出现。
- 辅助文字必须加深封面概念，不能成为随机填充。

## 色彩、材质与纹理
使用所选风格的色彩、材质与纹理逻辑：
{color_material_texture_rules}
结果必须像这个风格的成品封面作品，而不是表面贴了一个风格词。

## 负面约束
避免：
- {banned_elements}
- 通用封面版式。
- PPT / 课程封面感。
- 电商广告感。
- 无关装饰。
- 主标题缺失或不可读。
- 文章长文复制进画面。
- 风格特有失败：{avoid_when_applying_to_cover}

## 最终标准
只生成一张最终图。
不输出解释、备选方案、拼图、联系表或多方案构图。
最终图必须满足：
1. 明确是 {平台} 封面、比例 {ratio}。
2. 快速传达文章主题。
3. 把所选风格作为可见的组织语言。
4. 主标题可读、准确。
5. 视觉隐喻在场且风格原生。
6. 结果具备完整封面提示词的完备性与具体性，同时保持所选风格作为独立原子可复用。
```

## 编译说明

- 把蓝图改写成自然的最终提示词。不要留下 `{primary_visual_center}` 之类的元指令未消解。
- 多尺寸套图：每个目标比例编译一次本蓝图。每条编译后的提示词只请求一张独立构图并标明目标尺寸；不要用一条提示词请求拼图或联系表。
- 套图各目标保持内容、隐喻、风格身份、材质、配色一致，同时按比例重写尺度、字体、留白、阅读方向与空间行为。
- 风格文件 YAML 提供结构化字段时直接使用；风格正文里的语言用于恢复尚未结构化的细节。
- 最终提示词可加入风格专属小节，但不得加入第二个风格。
- 最终提示词应比风格原子更长、更完整，因为它包含封面形态、标题层级与内容适配。
- 生成文字类图片时（image_gen），提示词中的标题、副标题、标签等所有要出现的文字必须用中文引号“”标注。
