# 超大标题图文穿插

## 视觉风格原子
生成一张「超大标题 × 单一主体 × 图文穿插 × 有呼吸感」的编辑型海报。这不是普通的「图片上加字」，而是让文字真正进入画面，和主体形成前后遮挡、穿插、咬合的关系。整体像设计海报、杂志封面、展览视觉或品牌主视觉，不像普通公众号封面、PPT 封面、电商海报、信息流广告或廉价模板图。

## 用户输入
- 内容：{{一句标题 / 一段文案 / 一篇文章}}
- 图片比例：{{9:16 / 4:5 / 3:4 / 1:1 / 16:9 / 5:2 / 其他指定比例}}

## 一、先理解内容
先自动分析用户输入的内容，提炼出：
1. 这段内容最核心的主题；
2. 最值得被放大的主标题；
3. 最适合视觉化呈现的主体；
4. 这张海报更适合传达什么气质。
如果输入的是文章，而不是明确标题，自动提炼一个适合海报展示的短标题。
标题控制原则：
- 中文主标题优先控制在 2—8 个字；
- 英文主标题优先控制在 1—4 个单词；
- 标题要短、准、有力量，适合大字排版；
- 不要把完整长句直接当作主标题。
如果原文里有一句很适合做辅助说明，可以提炼一句极短副文案；如果没有，就不要硬加。

## 二、主体选择规则
根据主题，自动选择最合适的主视觉主体。主体不固定为某一种材质或某一种风格，可以是：真实人物、真实生活场景中的人或物、单一核心物件、扁平插画、剪影、拼贴、几何抽象图形、具象与抽象结合的概念图形。
优先原则：
1. 主体必须和标题语义直接相关；
2. 主体轮廓要清晰，适合和大字穿插；
3. 主体风格要根据主题自动变化；
4. 不要长期重复同一种主体语言。
主体风格分配逻辑：
- 主题偏生活方式、运动、工作、情绪、消费、日常 → 真实人物、真实动作、真实场景或真实物件；
- 主题偏设计、文化、审美、书籍、展览 → 插画、拼贴、剪影或图形化表达；
- 主题偏哲思、隐喻、抽象概念 → 可适度抽象化，但仍要保留一个明确主体；
- 主题偏科技、AI、系统、算法、未来 → 可以更概念化，但不要默认全部做成金属风。
重要限制：不要把「设计感」简单理解为金属雕塑、机器人、铬面人像或机械头部。设计感来自图文关系、版式层级和主体选择的准确性，而不是固定材质。
默认不要：每次都生成金属人 / 雕塑头像 / 机器人 / 未来感假人。
如果用人物：动作自然、姿态可信、保留真实感生活感现场感；不要遮住眼睛、鼻子、嘴巴等关键部位。
如果用抽象图：保持一个明确视觉焦点；不要做得太散、太碎、太装饰化。
整张画面只保留一个主视觉焦点。如需多人，也只能围绕同一个动作或同一个主题形成一个整体焦点，不要变成群像拼贴。

## 三、构图核心规则
整张图的固定构图语言为：
1. 超大标题跨越画面；
2. 一个核心主体占据视觉中心；
3. 标题与主体发生真实前后穿插；
4. 信息量克制；
5. 画面有留白、有呼吸感。
关键词：type over image / interleaved typography / foreground-background layering / editorial poster / modern graphic design / magazine cover aesthetic。
固定的是「图文关系」，不是固定主体类型，也不是固定配色模板。

## 四、最重要：图文穿插规则
主标题必须真正参与构图，而不是简单盖在图上。必须形成清晰的穿插关系：
- 一部分文字在主体后面；
- 一部分文字在主体前面；
- 主体局部遮挡文字；
- 文字局部压在主体前面；
- 形成明确的前景 / 中景 / 后景层次。
要求：
- 文字与主体之间要有真实咬合感；
- 即使有遮挡，标题依然要可读；
- 遮挡关系要经过设计，不要胡乱盖住；
- 不要整行半透明字；
- 不要只做「一个人物压在一整排字前面」的简单关系；
- 不要把背景字与前景字机械地分成上下两块；
- 让同一标题内部的字、词或局部笔画交替换层，至少出现两次清晰的前后关系切换；
- 在核心重叠区域同时看见「主体遮字」和「字压主体」；
- 不要显得扁平，要体现明显空间层次。
文字和主体要互相进入彼此的空间，而不是简单叠加。

## 五、标题排版规则
主标题必须是画面中最大的视觉元素之一。要求：
- 使用超大字号；可以跨越整个画面；可以分行；可以断行；可以局部超出版面；可以局部被裁切；可以与主体紧密咬合。
字体气质：粗体、高识别度、现代感、几何感、无衬线、平面设计感强。
不要使用：手写体、花体、书法体、幼稚可爱字体、过度装饰字体。
标题应该大胆，但不要因为做效果而影响识别。

## 六、版式与留白
整体版式要克制，不要过满，不要塞太多辅助信息。
- 保留明显留白；给主标题和主体足够呼吸感；让视线有停顿区；不要把每个角落都填满；不要做成满版轰炸式排版。
辅助信息要少：最多一条短副文案；最多少量小字；不要堆很多英文碎句；不要加大段说明文字；宁可留白，也不要乱填。
整张图信息层级最多三级：超大主标题 / 核心主体 / 极少量辅助信息。

## 七、比例适配规则
不要把同一套构图生硬套进所有尺寸。根据指定比例自动调整版式。
- `9:16`：纵向张力更强，标题可上下分区，主体可居中或偏上；
- `4:5`：适合封面感最强的排版，主体居中，标题围绕主体；
- `3:4`：保持均衡，标题与主体形成明显穿插；
- `1:1`：构图集中，主体与大字更紧密；
- `16:9`：横向展开，主体可偏左或偏右，标题横向拉开；
- `5:2`：横幅感更强，适合长标题拆分、单一主体、更多留白和横向延展。
无论什么比例，都要保持：一个主标题、一个主视觉焦点、明确层级、清晰穿插。

## 八、配色规则
不要固定成蓝色背景、粉色或红色辅助信息。配色要根据主题自动决定。
- 每张海报控制在 2—4 种主要颜色内；高对比、高识别度；有审美但不过度花哨；服务于主题气质。
可以是：黑白灰 / 米白+黑+橙 / 深绿+米白 / 酒红+奶白 / 淡粉+深紫 / 冷灰+电蓝 / 土黄+棕 / 其他合理方案。
强调色只用于小字、细线、节点或局部强调，不要让辅助色抢走主标题和主体的风头。

## 九、辅助图形元素
允许加入少量辅助图形，增强编辑设计感：细线、圆弧、节点、短横线、小型几何轨迹、极少量网格或标记。要求：很克制、数量少、只做辅助、不要喧宾夺主、不要做成复杂科技面板。

## 十、最终效果要求
最终画面必须满足：
- 一眼能看出「大字进入画面」；
- 标题与主体有真实前后穿插；
- 画面不是平铺叠加，而是有空间层次；
- 主体和标题都强，但不过满；
- 画面有呼吸感；
- 视觉风格统一；
- 审美现代、干净、利落、有冲击力。
优先保证四件事：超大标题、单一主视觉焦点、明确图文穿插、留白与呼吸感。这四件事比花哨细节更重要。
